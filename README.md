The JavaScript Basics Quiz is an interactive web application built using HTML, CSS, and vanilla JavaScript.
Users can select a quiz category, answer multiple-choice questions within a time limit, view their results, and review the correct answers at the end of each round.
The project was created to practise web development concepts while building something useful and engaging.

🎮 How to Play
1. Open the quiz website.
2. Select a quiz category.
3. Read the question and choose one of the four options.
4. Answer within 20 seconds.
5. Read the feedback and explanation.
6. Continue until all questions are completed.
7. View your score, rank, best streak, and answer review.
8. Start another round to practise again.
9. Each round contains 8 randomly selected questions.
